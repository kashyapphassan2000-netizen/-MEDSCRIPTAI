PART 0 - Start Here

0.1 What MedScriptAI is

MedScriptAI is your own medical assistant built on Meta's Llama-3.1-8B-Instruct. You take a general chat model and post-train it on open, benchmarked medical datasets so it gets better at three jobs: answering medical exam questions with an explanation (qa), turning a doctor-patient conversation into a clinical note (notes), and turning a clinical note into structured JSON (summary).

Post-training = everything done to a model after its expensive pre-training: supervised fine-tuning (SFT) teaches it the format and the domain from examples; preference optimisation (DPO) teaches it which of two answers is better. Companies do exactly this to turn base models into products (OpenAI, Meta, Google, AI2's Tulu 3, Hugging Face's Zephyr).

Where it is used in the real world: clinical documentation ("AI scribes" such as Nuance DAX, Abridge, Suki), medical education and exam prep, structured extraction from health records, and internal copilots at hospitals and insurers. Important: real clinical deployment needs regulatory approval and clinical validation; this project is an educational portfolio system, never a medical device.

1.2 Refreshers and 1-minute checks for every MUST item

Python basics. A dict maps keys to values; a list keeps order; a function groups steps. Check: without running it, what does this print?

row = {"task": "qa", "messages": [1, 2, 3]}
print(len(row["messages"]), row.get("source", "none"))

Answer: 3 none. If you got it right, you are ready.

JSON. JSON is text: objects use {}, arrays use [], strings MUST use double quotes. A .jsonl file has exactly one JSON object per line. Check: which line is invalid JSON?

{"role": "user", "content": "hi"}
{'role': 'user', 'content': 'hi'}

Answer: the second line (single quotes are Python, not JSON).

Linux terminal. pwd shows where you are, ls lists files, cd folder moves, cat file prints a file, mkdir -p a/b creates folders. Check: in a terminal type pwd, then mkdir -p test/one, then ls test. You should see one.

GPU and VRAM. A GPU runs the matrix maths of a neural network in parallel; VRAM is its memory. An 8B model in 16-bit needs about 16 GB just for weights (8 billion x 2 bytes); in 4-bit it needs about 5-6 GB. Check: how much VRAM do 14 billion parameters need in bfloat16? Answer: about 28 GB.

HTTP APIs. A client sends a request (method + URL + JSON body); the server answers with a status code (200 OK, 401 unauthorised, 422 invalid input, 500 server error) and a JSON body. Check: what status code should an API return when the API key is missing? Answer: 401.

PART 3 - The Core Idea

3.1 One analogy

Llama-3.1-8B-Instruct is a smart new graduate doctor. SFT is residency: you show thousands of worked examples ("here is a question, here is a correct answer in our house style") and it imitates them. DPO is the senior consultant reviewing two of the resident's notes and saying "this one is better than that one"; the resident shifts towards the better habits without forgetting everything else. LoRA means you do not rewrite the doctor's whole brain; you give them a slim specialty notebook (an adapter) that changes how they answer. QLoRA compresses the frozen textbook to fit in your backpack (4-bit) while the notebook stays full precision. vLLM multi-LoRA is one doctor carrying three specialty notebooks and picking the right one for each patient in milliseconds.

3.2 The 20% of ideas that explain 80% of the practice

  • Tokens and the chat template. Models read token IDs, not text. Llama-3.1 wraps each turn as <|start_header_id|>role<|end_header_id|> ... <|eot_id|>. Training and serving MUST use the same template, or quality silently drops.
  • Next-token loss with masking. SFT minimises cross-entropy on the next token, but only on the assistant's answer; system and user tokens are masked to -100 so the model does not learn to write questions.
  • LoRA. A frozen weight W gets a trainable low-rank update B x A of rank r (we use r=16). Effective change = (alpha/r) x B x A. You train about 42 million parameters instead of 8 billion.
  • QLoRA. The frozen base is stored in 4-bit NF4; LoRA weights stay in 16-bit. Memory falls from about 16 GB to about 6 GB for weights, so an 8B model trains on one GPU.
  • Learning rate and epochs. LoRA SFT works at about 2e-4 for 1-3 epochs; DPO needs about 5e-6 (40x smaller). Too high = loss spikes and broken grammar; too many epochs = memorisation (validation loss goes up while training loss keeps falling).
  • Data quality beats data size. De-duplicate, filter invalid rows (25% of the clinical summaries are broken JSON), and never let test questions leak into training (contamination).
  • Preference optimisation. DPO needs (prompt, chosen, rejected). Its loss starts at ln 2 = 0.693 and falls as the model prefers chosen answers. beta (0.1) controls how far it may drift from the reference (SFT) model.
  • Evaluation is a system, not a number. Exact accuracy for multiple choice, overlap (ROUGE-L) and meaning (BERTScore) for text, an LLM judge for quality, and statistics to know whether a difference is real.
  • Serving. vLLM keeps the 16 GB base model once in GPU memory and adds the small adapter matrices per request, so three adapters cost almost the same as one model. Clients choose an adapter through the model field of an OpenAI-style request.
  • Production. A stateless API container in front of the model server, secrets outside the code, logs and traces, an image registry (ECR), a GPU host (EC2), least-privilege IAM, and a teardown plan.

def write_jsonl(path, rows):
    """Write a list of dicts to a .jsonl file (one JSON object per line)."""
    path = Path(path)
    path.parent.mkdir(parents=True, exist_ok=True)       # create folders if missing
    with path.open("w", encoding="utf-8") as f:
        for row in rows:

    print(f"wrote {len(rows):>6} rows -> {path.relative_to(ROOT)}")

    """Read a .jsonl file back into a list of dicts."""
    with Path(path).open(encoding="utf-8") as f:
        return [json.loads(line) for line in f if line.strip()]

    return msgs

"""Step 2: clean the raw data and convert it to chat-format .jsonl (one file per task and split)."""
import json                                        # parse the JSON summaries
import random                                      # repeatable shuffling
import re                                          # simple text clean-up
from common import RAW, SFT, PREF, chat, read_jsonl, write_jsonl

random.seed(42)                                    # same split every time you run it
MAX_CHARS = 7000                                   # ~1,750 tokens: fits max_seq_length 2048
LETTERS = "ABCD"


def clean(text):
    """Collapse repeated spaces/newlines and strip the ends."""
    return re.sub(r"[ \t]+", " ", re.sub(r"\n{3,}", "\n\n", str(text or ""))).strip()


def key(text):
    """Normalised text used to find duplicates (lower-case, letters and digits only)."""
    return re.sub(r"[^a-z0-9]", "", text.lower())[:300]


def mcq_prompt(question, options):
    """Question + lettered options, the exact user message format for the qa adapter."""
    lines = [f"{letter}) {text}" for letter, text in options]
    return f"{clean(question)}\n\nOptions:\n" + "\n".join(lines)


def short(text, limit=900):
    """Cut long explanations at the last full stop before `limit` characters."""
    text = clean(text)
    if len(text) <= limit:
        return text
    cut = text[:limit].rsplit(".", 1)[0]
    return cut + "."


# ---------- QA task: MedQA + MedMCQA + PubMedQA ----------
def from_medqa(row):
    opts = sorted(row["options"].items())          # [("A", "..."), ("B", "..."), ...]
    letter = row["answer_idx"]
    answer = f"Answer: {letter}) {clean(row['answer'])}"   # no explanation in MedQA (Part 5 adds one)
    return {"task": "qa", "source": "medqa", "answer_letter": letter,
            "question_key": key(row["question"]),
            "messages": chat("qa", mcq_prompt(row["question"], opts), answer)}


def from_medmcqa(row):
    if row.get("choice_type") != "single" or row.get("cop") not in (0, 1, 2, 3):
        return None                                # skip multi-answer or broken rows
    opts = list(zip(LETTERS, [row["opa"], row["opb"], row["opc"], row["opd"]]))
    letter = LETTERS[row["cop"]]
    answer = f"Answer: {letter}) {clean(opts[row['cop']][1])}"
    if row.get("exp") and len(clean(row["exp"])) > 40:
        answer += f"\nExplanation: {short(row['exp'])}"
    return {"task": "qa", "source": "medmcqa", "answer_letter": letter,
            "question_key": key(row["question"]),
            "messages": chat("qa", mcq_prompt(row["question"], opts), answer)}


def from_pubmedqa(row):
    context = clean(" ".join(row["context"]["contexts"]))
    opts = [("A", "yes"), ("B", "no"), ("C", "maybe")]
    letter = {"yes": "A", "no": "B", "maybe": "C"}[row["final_decision"]]
    question = f"Context: {context}\n\nQuestion: {row['question']}"
    answer = f"Answer: {letter}) {row['final_decision']}\nExplanation: {short(row['long_answer'])}"
    return {"task": "qa", "source": "pubmedqa", "answer_letter": letter,
            "question_key": key(row["question"]),
            "messages": chat("qa", mcq_prompt(question, opts), answer)}


# ---------- notes + summary tasks: augmented clinical notes ----------
def compact(value):
    """Drop empty fields ("None", "", [], {}) so the target JSON is short and factual."""
    if isinstance(value, dict):
        out = {k: compact(v) for k, v in value.items()}
        return {k: v for k, v in out.items() if v not in (None, "", [], {})}
    if isinstance(value, list):
        out = [compact(v) for v in value]
        return [v for v in out if v not in (None, "", [], {})]
    if isinstance(value, str) and value.strip().lower() in ("none", "n/a", ""):
        return None
    return value


def from_clinical(row):
    """One raw row gives one 'notes' example and one 'summary' example (or None if broken)."""
    conversation, note = clean(row["conversation"]), clean(row["note"])
    try:
        summary = compact(json.loads(row["summary"]))   # ~25% of summaries are invalid JSON
    except (json.JSONDecodeError, TypeError):
        return None
    if not conversation or not note or not summary:
        return None
    summary_text = json.dumps(summary, ensure_ascii=False)
    notes_ex = {"task": "notes", "source": "clinical_notes", "id": row["idx"],
                "messages": chat("notes", conversation, note)}
    summary_ex = {"task": "summary", "source": "clinical_notes", "id": row["idx"],
                  "messages": chat("summary", note, summary_text)}
    return notes_ex, summary_ex


def fits(example):
    """Keep only examples short enough for max_seq_length=2048."""
    return sum(len(m["content"]) for m in example["messages"]) <= MAX_CHARS


def build(rows, fn):
    """Apply a converter, drop None/too-long rows."""
    out = [fn(r) for r in rows]
    return [x for x in out if x is not None]


# ---- QA: build, de-duplicate, split ----
def sample(rows, n):
    """Random n rows (or all of them if there are fewer than n)."""
    return random.sample(rows, min(n, len(rows)))

           + sample(build(read_jsonl(RAW / "medmcqa_val.jsonl"), from_medmcqa), 200))

           + build(read_jsonl(RAW / "medmcqa_train.jsonl"), from_medmcqa)
           + pubmed[100:])

    from transformers import AutoTokenizer
    tok = AutoTokenizer.from_pretrained(BASE_MODEL)
except Exception as exc:                            # still validate structure without it
    tok = None
    print(f"(tokenizer not loaded, skipping token counts: {exc.__class__.__name__})")

    lengths = []
    for n, line in enumerate(path.open(encoding="utf-8"), start=1):
        try:
            row = json.loads(line)                  # 1) each line must be valid JSON
            roles = [m["role"] for m in row["messages"]]
            assert roles == ROLES, f"roles {roles}"  # 2) exactly system -> user -> assistant
            assert all(m["content"].strip() for m in row["messages"]), "empty message"

4.8 Common mistake at this level

The mistake: training on text that is formatted differently from what the server sends at inference. Examples: two <|begin_of_text|> tokens (fixed in 10_train_sft.py), a different system prompt in the API, or a missing chat template. The model then underperforms and you blame the hyper-parameters.

How to spot it: print one formatted training example (10_train_sft.py does this), print the exact messages your API sends, and compare token by token. The repo avoids the problem by importing SYSTEM from one file everywhere.

def letter(text):
    """'Answer: C) ...' -> 'C' (None if the model did not follow the format)."""
    if text and "Answer:" in text:
        tail = text.split("Answer:", 1)[1].strip()
        return tail[:1].upper() or None
    return None


def is_json(text):
    try:
        json.loads(text.strip().removeprefix("```json").removesuffix("```").strip())
        return True
    except (json.JSONDecodeError, AttributeError):
        return False


results = {}
for task in a.tasks:
    for path in sorted(Path(OUT / "preds" / task).glob("*.jsonl")):
        rows = read_jsonl(path)
        preds = [r["prediction"] or "" for r in rows]
        refs = [r["reference"] for r in rows]
        m = {"n": len(rows)}
        m["rougeL"] = sum(rouge.score(ref, pred)["rougeL"].fmeasure for ref, pred in zip(refs, preds)) / len(rows)
        _, _, f1 = bert_score(preds, refs, model_type=a.bert_model, lang="en", verbose=False)
        m["bertscore_f1"] = f1.mean().item()

        if task == "summary":

        results[f"{task}/{path.stem}"] = {k: round(v, 4) if isinstance(v, float) else v for k, v in m.items()}

--mode score     one answer at a time, 1-5 rubric score            (Part 5)
--mode pairwise  model A vs model B, run twice with order swapped    (Part 6)
                 -> removes position bias: a "win" must win in BOTH orders
"""
import argparse
import json
import os
import re
from concurrent.futures import ThreadPoolExecutor
from openai import OpenAI
from common import OUT, read_jsonl

p = argparse.ArgumentParser()
p.add_argument("--task", required=True, choices=["qa", "notes", "summary"])
p.add_argument("--mode", default="score", choices=["score", "pairwise"])
p.add_argument("--models", nargs="+", required=True, help="score: any number; pairwise: exactly two (A B)")
p.add_argument("--n", type=int, default=100)
a = p.parse_args()

judge = OpenAI(base_url=os.getenv("JUDGE_URL", "http://localhost:8001/v1"), api_key="EMPTY")
JUDGE_MODEL = os.getenv("JUDGE_MODEL", "teacher")
RUBRIC = {
    "qa": "correct final answer (vs the reference), sound medical reasoning, no unsafe advice",
    "notes": "faithful to the conversation (no invented facts), complete key findings, clear clinical style",
    "summary": "valid JSON, every value supported by the note, no important fact missing",
}


def ask_json(prompt):
    """Call the judge at temperature 0 and pull the first {...} object out of the reply."""
    text = judge.chat.completions.create(
        model=JUDGE_MODEL, temperature=0.0, max_tokens=300,
        messages=[{"role": "user", "content": prompt}]).choices[0].message.content
    match = re.search(r"\{.*\}", text, re.DOTALL)
    try:
        return json.loads(match.group(0)) if match else {}
    except json.JSONDecodeError:
        return {}


def score_prompt(row):
    return (f"You are a strict medical expert grader. Criteria: {RUBRIC[a.task]}.\n\n"
            f"TASK INPUT:\n{row['prompt'][:4000]}\n\nREFERENCE ANSWER:\n{row['reference'][:3000]}\n\n"
            f"MODEL ANSWER:\n{row['prediction'][:3000]}\n\n"
            'Return ONLY a JSON object: {"score": <1-5>, "reason": "<one sentence>"}')


def pair_prompt(row, first, second):
    return (f"You are a strict medical expert judge. Criteria: {RUBRIC[a.task]}.\n\n"
            f"TASK INPUT:\n{row['prompt'][:4000]}\n\nREFERENCE ANSWER:\n{row['reference'][:3000]}\n\n"
            f"ANSWER A:\n{first[:3000]}\n\nANSWER B:\n{second[:3000]}\n\n"
            'Which answer is better? Return ONLY a JSON object: {"winner": "A" or "B" or "tie", "reason": "..."}')


preds = {m: read_jsonl(OUT / "preds" / a.task / f"{m}.jsonl")[: a.n] for m in a.models}
report = {}
with ThreadPoolExecutor(max_workers=16) as pool:
    if a.mode == "score":
        for m, rows in preds.items():
            scores = [r.get("score") for r in pool.map(lambda row: ask_json(score_prompt(row)), rows)]
            valid = [s for s in scores if isinstance(s, (int, float))]
            report[m] = {"mean_score": round(sum(valid) / max(len(valid), 1), 3), "judged": len(valid)}
    else:
        ma, mb = a.models
        rows_a, rows_b = preds[ma], preds[mb]

        def duel(i):
            ab = ask_json(pair_prompt(rows_a[i], rows_a[i]["prediction"], rows_b[i]["prediction"]))
            ba = ask_json(pair_prompt(rows_a[i], rows_b[i]["prediction"], rows_a[i]["prediction"]))
            first, second = ab.get("winner"), ba.get("winner")
            if first == "A" and second == "B":
                return ma                                  # A won in both orders
            if first == "B" and second == "A":
                return mb
            return "tie"                                   # disagreement across orders = tie

        outcomes = list(pool.map(duel, range(min(len(rows_a), len(rows_b)))))
        n = len(outcomes)
        report = {f"{ma}_wins": round(outcomes.count(ma) / n, 3),
                  f"{mb}_wins": round(outcomes.count(mb) / n, 3),
                  "ties": round(outcomes.count("tie") / n, 3), "n": n,
                  "per_item": outcomes}                    # kept for judge-vs-human agreement (Part 7)

print(json.dumps({k: v for k, v in report.items() if k != "per_item"}, indent=1))
path = OUT / "reports" / f"judge_{a.task}_{a.mode}_{'_vs_'.join(a.models)}.json"
path.parent.mkdir(parents=True, exist_ok=True)
path.write_text(json.dumps(report, indent=1))

5.10 Common mistake at this level

The mistake: celebrating a metric that does not measure what you think. Examples: ROUGE-L goes up because the fine-tuned model copies the reference style while facts get worse; accuracy goes up because test questions leaked into training; the judge prefers the fine-tuned model because it writes like the judge.

How to spot it: always read 10 random predictions next to the references; check format_ok before accuracy; keep the decontamination step (Section 4.2) and the contamination check (Section 7.1); compare at least two independent metrics; run the significance test (Section 7.2) before claiming a win.

PART 6 - ADVANCED: DPO, multi-LoRA serving, production API and cloud deployment

6.0 Concept

What: build preference pairs from your own SFT model's answers, align the model with DPO, serve base + all adapters from one vLLM process with hot-swapping, put a FastAPI service with LangSmith tracing in front, package it with Docker, push it to ECR and run it on an AWS GPU machine (rehearsed first on FakeCloud).

Why: SFT teaches the model to imitate; DPO teaches it to prefer better answers, which improves correctness, safety and style without a separate reward model or RL loop. Serving and deployment turn a notebook experiment into a system other people can call.

When: DPO after SFT has converged and you can produce comparisons; deployment once the evaluation says the model is worth serving.

Harder than Part 5 because: you now generate data with your own model, train against a reference model, run two GPU servers plus an API, and operate cloud resources that cost real money. Budget: about 5 GPU-hours (about US$7) + about US$3-5 on AWS if you do the blue column.

"""Part 6: build DPO preference pairs (prompt, chosen, rejected) with distilabel.

For each held-out prompt we collect 3 candidate answers:
  2 samples from YOUR SFT adapter (served by vLLM under the adapter name, e.g. "qa")
  1 answer from the teacher model
The teacher then rates all 3 (UltraFeedback, 1-5). For qa we ALSO check the letter against the gold answer,
because a verifiable signal beats any judge. Best candidate = chosen, worst = rejected.
"""
import argparse
import os
from distilabel.models import OpenAILLM
from distilabel.pipeline import Pipeline
from distilabel.steps import GroupColumns, LoadDataFromDicts
from distilabel.steps.tasks import TextGeneration, UltraFeedback
from common import PREF, SYSTEM, read_jsonl, write_jsonl

p = argparse.ArgumentParser()
p.add_argument("--task", default="qa", choices=["qa", "notes", "summary"])
p.add_argument("--limit", type=int, default=1500)
a = p.parse_args()

STUDENT_URL = os.getenv("STUDENT_URL", "http://localhost:8000/v1")  # vLLM with your SFT adapters
TEACHER_URL = os.getenv("TEACHER_URL", "http://localhost:8001/v1")  # vLLM with the teacher
TEACHER = os.getenv("TEACHER_MODEL", "teacher")

rows = read_jsonl(PREF / f"{a.task}_dpo.jsonl")[: a.limit]
inputs = [{"instruction": r["messages"][1]["content"],                 # the user message
           "gold_letter": r.get("answer_letter")} for r in rows]       # None for notes/summary


def llm(model, url, temperature):
    return OpenAILLM(model=model, base_url=url, api_key="EMPTY",
                     generation_kwargs={"temperature": temperature, "max_new_tokens": 700})


with Pipeline(name=f"medscriptai-dpo-{a.task}") as pipeline:
    load = LoadDataFromDicts(data=inputs, batch_size=64)
    student_1 = TextGeneration(name="student_1", llm=llm(a.task, STUDENT_URL, 0.9),
                               system_prompt=SYSTEM[a.task], input_batch_size=32)
    student_2 = TextGeneration(name="student_2", llm=llm(a.task, STUDENT_URL, 0.9),
                               system_prompt=SYSTEM[a.task], input_batch_size=32)
    teacher = TextGeneration(name="teacher", llm=llm(TEACHER, TEACHER_URL, 0.3),
                             system_prompt=SYSTEM[a.task], input_batch_size=32)
    group = GroupColumns(columns=["generation", "model_name"],          # 3 single answers -> 1 list
                         output_columns=["generations", "generation_models"])
    rate = UltraFeedback(llm=llm(TEACHER, TEACHER_URL, 0.0), aspect="overall-rating", input_batch_size=16)
    load >> [student_1, student_2, teacher] >> group >> rate            # fan out, then join

data = pipeline.run(use_cache=False)["default"]["train"]


def letter_of(text):
    """Read the letter after 'Answer:' ('Answer: C) ...' -> 'C')."""
    if text and "Answer:" in text:
        tail = text.split("Answer:", 1)[1].strip()
        return tail[:1].upper() if tail else None
    return None


pairs = []
for row in data:
    scored = []
    for text, rating in zip(row["generations"], row["ratings"]):
        if not text or rating is None:
            continue
        correct = 1 if row["gold_letter"] and letter_of(text) == row["gold_letter"] else 0
        scored.append((correct * 10 + rating, text))    # correctness dominates, rating breaks ties
    if len(scored) < 2:
        continue
    scored.sort(key=lambda s: s[0])
    (low, rejected), (high, chosen) = scored[0], scored[-1]
    if high - low < 2:                                  # too similar = weak training signal, skip
        continue
    system = {"role": "system", "content": SYSTEM[a.task]}
    pairs.append({"prompt": [system, {"role": "user", "content": row["instruction"]}],
                  "chosen": [{"role": "assistant", "content": chosen}],
                  "rejected": [{"role": "assistant", "content": rejected}],
                  "score_chosen": high, "score_rejected": low})

write_jsonl(PREF / f"{a.task}_pairs.jsonl", pairs)
print(f"{len(pairs)} preference pairs from {len(inputs)} prompts")

class GenerateRequest(BaseModel):
    task: str = Field(pattern="^(qa|notes|summary)$", examples=["qa"])
    input: str = Field(min_length=1, max_length=20000)
    max_tokens: int = Field(default=700, ge=1, le=2000)
    temperature: float = Field(default=0.0, ge=0.0, le=1.5)


class GenerateResponse(BaseModel):
    request_id: str
    task: str
    model: str
    output: str
    parsed_json: dict | None = None               # filled for task="summary" when the output is valid JSON
    latency_ms: int
    disclaimer: str = "AI-generated. For education/documentation support only. Not medical advice."


@traceable(name="medscriptai.generate", run_type="chain")
def run_generation(task: str, text: str, max_tokens: int, temperature: float) -> dict:
    model = TASK_TO_MODEL[task]
    resp = llm.chat.completions.create(
        model=model,
        messages=[{"role": "system", "content": SYSTEM[task]}, {"role": "user", "content": text}],
        max_tokens=max_tokens,
        temperature=temperature,
    )
    return {"model": model, "output": resp.choices[0].message.content or ""}


@app.get("/health")
def health():
    """Liveness: the API process is up."""
    return {"status": "ok"}


@app.get("/ready")
def ready():
    """Readiness: vLLM answers and every adapter we route to is loaded."""
    try:
        served = {m.id for m in llm.models.list().data}
    except Exception as exc:
        raise HTTPException(503, f"vLLM not reachable: {exc.__class__.__name__}")
    missing = sorted(set(TASK_TO_MODEL.values()) - served)
    if missing:
        raise HTTPException(503, f"adapters not loaded in vLLM: {missing}")
    return {"status": "ready", "models": sorted(served)}


@app.post("/v1/generate", response_model=GenerateResponse)
def generate(req: GenerateRequest, x_api_key: str = Header(default="")):
    if API_KEY and x_api_key != API_KEY:
        raise HTTPException(401, "invalid or missing X-API-Key header")
    start = time.perf_counter()
    try:
        result = run_generation(req.task, req.input, req.max_tokens, req.temperature)
    except Exception as exc:
        raise HTTPException(502, f"model backend error: {exc.__class__.__name__}")
    parsed = None
    if req.task == "summary":
        try:
            parsed = json.loads(result["output"])
        except json.JSONDecodeError:
            parsed = None
    return GenerateResponse(request_id=str(uuid.uuid4()), task=req.task, model=result["model"],
                            output=result["output"], parsed_json=parsed,
                            latency_ms=int((time.perf_counter() - start) * 1000))

"""Elite check: is any TEST question a near-copy of a TRAINING question? (13-gram overlap, GPT-3 paper style)

Exact-match de-duplication (step 2) misses near-copies: the same question with one word changed.
Medical exams share stock phrases ("is brought to the emergency department because of a 2-day history of",
lab panels), so ONE shared 13-gram proves nothing. We flag a test question only when at least
50% of its 13-grams come from a SINGLE training question.
"""
import re
from collections import Counter, defaultdict
from common import SFT, read_jsonl

N = 13                       # n-gram length in words
THRESHOLD = 0.5              # share of the test question's n-grams found in one training question


def grams(text):
    text = text.split("\n\nOptions:")[0]                 # compare the question stem, not the option labels
    words = re.findall(r"[a-z0-9]+", text.lower())
    return {" ".join(words[i:i + N]) for i in range(len(words) - N + 1)}


for task in ["qa", "notes", "summary"]:
    index = defaultdict(set)                             # n-gram -> ids of training rows containing it
    path = SFT / f"{task}_train.jsonl"
    if path.exists():
        for row_id, row in enumerate(read_jsonl(path)):
            for g in grams(row["messages"][1]["content"]):
                index[g].add(row_id)
    test = read_jsonl(SFT / f"{task}_test.jsonl")
    flagged = []
    for row in test:
        test_grams = grams(row["messages"][1]["content"])
        per_train_row = Counter(i for g in test_grams for i in index.get(g, ()))
        best = per_train_row.most_common(1)[0][1] if per_train_row else 0
        if test_grams and best / len(test_grams) >= THRESHOLD:
            flagged.append(row["messages"][1]["content"][:110].replace("\n", " "))
    print(f"{task:8} test rows={len(test):4}  near-duplicates of training rows={len(flagged):3} "
          f"({len(flagged) / max(len(test), 1):.1%})")
    for text in flagged[:3]:
        print("   e.g.", text)

What we learned while building this (a real elite lesson): the first version flagged 13% of QA test questions as contaminated after exact de-duplication. """Elite check: is model B REALLY better than model A, or is it noise? Paired bootstrap on QA accuracy.

python scripts/33_significance.py --a qa --b qa-dpo
"""
import argparse
import random
from common import OUT, read_jsonl

p = argparse.ArgumentParser()
p.add_argument("--a", required=True)
p.add_argument("--b", required=True)
p.add_argument("--rounds", type=int, default=10000)
args = p.parse_args()


def correct(row):
    pred = row["prediction"] or ""
    letter = pred.split("Answer:", 1)[1].strip()[:1].upper() if "Answer:" in pred else None
    return int(letter == row["answer_letter"])


a = [correct(r) for r in read_jsonl(OUT / "preds" / "qa" / f"{args.a}.jsonl")]
b = [correct(r) for r in read_jsonl(OUT / "preds" / "qa" / f"{args.b}.jsonl")]
n = min(len(a), len(b))
diffs = []
rng = random.Random(0)
for _ in range(args.rounds):
    idx = [rng.randrange(n) for _ in range(n)]          # resample the SAME questions for both models
    diffs.append(sum(b[i] - a[i] for i in idx) / n)
diffs.sort()
low, high = diffs[int(0.025 * args.rounds)], diffs[int(0.975 * args.rounds)]
observed = (sum(b[:n]) - sum(a[:n])) / n
print(f"accuracy {args.a}={sum(a[:n]) / n:.3f}  {args.b}={sum(b[:n]) / n:.3f}  diff={observed:+.3f}")
print(f"95% CI of the difference: [{low:+.3f}, {high:+.3f}]")
print("SIGNIFICANT" if low > 0 or high < 0 else "NOT significant: the CI contains 0, do not claim an improvement")

"""Elite check: criterion-level scoring for the summary task (rubric idea from HealthBench, made verifiable).

Every field path in the REFERENCE JSON is one criterion, e.g. "patient information.age".
recall    = reference fields the model filled       (missing facts lower it)
precision = model fields that exist in the reference (invented fields lower it = hallucination signal)
"""
import argparse
import json
from common import OUT, read_jsonl

p = argparse.ArgumentParser()
p.add_argument("--models", nargs="+", default=["base", "summary"])
a = p.parse_args()


def paths(value, prefix=""):
    """{"a": {"b": 1}, "c": [{"d": 2}]} -> {"a.b", "c.d"} (list items are merged)."""
    out = set()
    if isinstance(value, dict):
        for k, v in value.items():
            out |= paths(v, f"{prefix}{k.lower().strip()}.")
    elif isinstance(value, list):
        for v in value:
            out |= paths(v, prefix)
    elif value not in (None, "", "None"):
        out.add(prefix.rstrip("."))
    return out


def load(text):
    try:
        return json.loads((text or "").strip().removeprefix("```json").removesuffix("```").strip())
    except json.JSONDecodeError:
        return None


for model in a.models:
    rows = read_jsonl(OUT / "preds" / "summary" / f"{model}.jsonl")
    tp = fp = fn = invalid = 0
    for r in rows:
        ref, pred = paths(load(r["reference"]) or {}), load(r["prediction"])
        if pred is None:
            invalid += 1
            fn += len(ref)                     # an unreadable answer misses every criterion
            continue
        got = paths(pred)
        tp += len(ref & got)
        fp += len(got - ref)
        fn += len(ref - got)
    precision = tp / max(tp + fp, 1)
    recall = tp / max(tp + fn, 1)
    f1 = 2 * precision * recall / max(precision + recall, 1e-9)
    print(f"{model:10} field precision={precision:.3f} recall={recall:.3f} F1={f1:.3f} invalid_json={invalid}/{len(rows)}")

7.8 What elite teams would do next (pick one as your stretch goal)

  • RL with verifiable rewards (GRPO). For multiple-choice QA the reward is checkable (correct letter = 1). TRL's GRPOTrainer and Unsloth support it; this is the DeepSeek-R1 / Tulu 3 style of post-training (verify current TRL/Unsloth GRPO docs).
  • Other preference losses. Compare DPO with SimPO (loss_type="sigmoid_norm" in TRL), IPO, KTO or ORPO on the same pairs; report the significance test for each.
  • Iterative on-policy DPO. Regenerate pairs with the DPO model and train a second round; stop when the win rate stops moving.
  • Serving efficiency. FP8 or AWQ-quantised base model for serving, prefix caching for the long shared system prompt, speculative decoding; measure tokens/second and cost per 1,000 requests.
  • Safety evaluation. A red-team set (self-harm, dosage requests, emergencies) with expected refusals or escalation messages; track refusal rate next to helpfulness.
  • Privacy and regulation. Real clinical notes contain PHI: de-identify, keep traces private (self-hosted LangSmith or redaction), and know that software making clinical decisions is regulated (for example FDA "software as a medical device").

7.9 Common mistake at this level

The mistake: running elite-looking analyses that are not tied to a decision: a kappa nobody reads, a CI computed on a different test set than the headline number, a contamination check run after the paper is written.

How to spot it: every analysis answers one question that would change what you ship or what you claim. Write the question first ("is DPO better than SFT on QA accuracy?"), then the analysis, then the decision ("ship qa-dpo" or "keep qa").

ANSWER KEY

1. The trainer adds <|begin_of_text|> again, so every example starts with two BOS tokens. Training still runs, but the model learns from a sequence it never sees at inference (vLLM sends one BOS), which can hurt quality. The CPU smoke test caught exactly this.

2. 7,040 / (8 x 2) = 440 optimizer steps.

3. The default --max-loras is 1, so only one adapter can be active in a GPU batch; requests for the other two adapters wait for the next batches. Latency rises even though the GPU has capacity. With --max-loras 4 all three run in the same batch.

4. About 0.693 (= ln 2). At step 0 the policy equals the reference (the frozen "ref" copy of the SFT adapter), so both log-ratios are 0, the margin is 0 and -log(sigmoid(0)) = ln 2.

5. aws --endpoint-url http://localhost:4566 ecr describe-images --repository-name medscriptai-api (or set AWS_ENDPOINT_URL and drop the flag).

6. GPU billing stops, the root disk is kept, but /ephemeral is wiped, so the cache is lost (it re-downloads automatically). After Restore: run mkdir -p /ephemeral/hf-cache, update the IP if it changed, and restart FakeCloud.

7. Only that the observed difference is +1.6 points and NOT statistically significant: the interval contains 0. Do not claim an improvement; collect more test data or a bigger effect.

8. With swapping, A-then-B gives "A" (model 1) and B-then-A gives "A" (model 2), so the orders disagree and every item becomes a tie. The win rates are 0/0 and ties 100%: a clear signal of a broken or position-biased judge.

9. Set MODEL_QA=qa in deploy/.env and run docker compose --env-file .env up -d api in the deploy folder (only the API container restarts).

10. Least privilege: if the machine is compromised, the attacker can only read MedScriptAI's own image, bucket and secrets, not every image, bucket and secret in the account. "Resource": "*" is kept only for ecr:GetAuthorizationToken (it has no resource) and logs.
