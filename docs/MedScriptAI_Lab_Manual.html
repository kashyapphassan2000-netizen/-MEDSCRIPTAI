PART 0 - Start Here

0.1 What MedScriptAI is (in plain words)

MedScriptAI is your own medical AI assistant. You take Meta's Llama-3.1-8B-Instruct (a general chatbot model with 8 billion parameters) and teach it three medical jobs: answer medical exam questions with an explanation (qa), turn a doctor-patient conversation into a clinical note (notes), and turn a clinical note into structured JSON data (summary).

Teaching an existing model new behaviour is called post-training. You will do the two most important kinds: SFT (supervised fine-tuning: show the model thousands of examples of correct answers) and DPO (direct preference optimisation: show the model pairs of answers and tell it which one is better).

Real-world use: AI medical scribes (Nuance DAX, Abridge, Suki), exam-prep tutors, extraction of structured data from health records, hospital copilots. Important: real clinical use needs regulatory approval; this project is an educational portfolio system, never a medical device.

1.2 Refreshers and 1-minute checks

Python. A dict maps keys to values; a list keeps order. Check: what does this print?

row = {"task": "qa", "messages": [1, 2, 3]}
print(len(row["messages"]), row.get("source", "none"))

Answer: 3 none.

JSON. Text format: {} objects, [] arrays, strings MUST use double quotes. A .jsonl file has one JSON object per line. Check: which line is NOT valid JSON?

{"role": "user", "content": "hi"}
{'role': 'user', 'content': 'hi'}

Answer: the second (single quotes are Python, not JSON).

Terminal. pwd = where am I; ls = list files; cd folder = go into folder; cd .. = go up one folder; mkdir -p a/b = make folders; cat file = print a file. Check: after mkdir -p test/one and ls test you should see one.

GPU and VRAM. The GPU does the maths of the model in parallel; VRAM is the GPU's memory. 8 billion parameters x 2 bytes (16-bit) = 16 GB just for the weights; in 4-bit about 5-6 GB. Check: how much VRAM do 14 billion parameters need in 16-bit? Answer: about 28 GB.

HTTP APIs. A client sends a request (method, URL, JSON body); the server answers with a status code (200 OK, 401 not authorised, 422 invalid input, 500 server error) and JSON. Check: which code means "your API key is missing"? Answer: 401.

Your laptop has no strong GPU, so you rent one. Hyperstack is a cloud company that rents computers with NVIDIA GPUs by the hour. PART 3 - The Core Idea (read this before you write any code)

3.1 One analogy for the whole project

Llama-3.1-8B-Instruct is a smart new graduate doctor who knows a lot but does not write in your hospital's style. SFT (supervised fine-tuning) is residency: you show thousands of worked examples and the doctor imitates them. DPO (preference optimisation) is a senior consultant who looks at two of the doctor's notes and says "this one is better"; the doctor shifts towards the better habits. LoRA means you do not rewrite the doctor's whole brain; you hand them a slim specialty notebook (an adapter). QLoRA compresses the textbook to fit in a backpack (4-bit) while the notebook stays sharp. vLLM multi-LoRA is one doctor carrying three notebooks (qa, notes, summary) and opening the right one for each patient in milliseconds.

3.2 Tokens and the chat template

A model never sees letters. A tokenizer cuts text into tokens (word pieces) and turns each into a number. Llama-3.1 has 128,256 different tokens. "Nitrofurantoin" becomes several tokens; "the" is one.

A chat model also needs to know WHO is speaking. Llama-3.1 uses special tokens around every message. This is the exact text the model sees for one of your training examples (shortened):

Today Date: 26 Jul 2024

Rule: training and serving must produce EXACTLY this format. That is why every script imports the same system prompts from one file (scripts/common.py).

3.3 What "training" actually does

The model predicts the next token, one at a time. Training shows it a correct example and measures how surprised it was by each real next token. That surprise is the loss (cross-entropy). An optimizer nudges the weights so that next time the loss is a bit lower.

Tiny example: after "Answer: C) Accidental exogenous", the correct next token is "Insulin". If the model gave "Insulin" a probability of 0.05, the loss for that token is -ln(0.05) = 3.0. After training it gives 0.9, loss -ln(0.9) = 0.1.

Loss masking: we only want the model to learn to WRITE ANSWERS, not to write questions. So the loss is computed only on the assistant part; the system and user tokens are masked (their label is set to -100, which means "ignore").

3.4 LoRA in numbers

One attention matrix in Llama-3.1-8B (q_proj) is 4,096 x 4,096 = 16.8 million numbers. Full fine-tuning would change all of them, in every one of the 32 layers, plus all the other matrices: 8 billion numbers, about 16 GB of weights plus optimizer state that is several times bigger.

LoRA freezes the big matrix W and learns two thin matrices B (4,096 x 16) and A (16 x 4,096) instead. Their product B x A has the same shape as W, but only 2 x 4,096 x 16 = 131,072 trainable numbers. With adapters on 7 matrices in 32 layers you train about 42 million numbers (0.5% of the model). The saved adapter file is only about 80-170 MB.

LoRA settingOur valueMeaning

lora_alpha16scaling: the update is multiplied by alpha / r = 1.0
target_modulesq, k, v, o, gate, up, downwhich matrices get an adapter (all linear layers works best)

3.5 QLoRA: making an 8B model fit

QLoRA stores the frozen base weights in 4-bit (the NF4 format) instead of 16-bit: 16 GB becomes about 5.7 GB. The small LoRA matrices stay in 16-bit and are the only part trained. Quality stays close to full 16-bit LoRA (QLoRA paper, Dettmers et al. 2023). Unsloth adds fast custom GPU code on top, about 2x faster with less memory.

Leakage (contamination) means a test question, or a near-copy of it, is also in the training data. Then the score measures memory, not skill. While building this manual, the full-data run found that the clinical-notes dataset repeats 927 notes up to 5 times under different IDs, so 14-18% of the notes/summary test items had a copy in training. The data script now removes repeated notes before splitting (result: 0.0%). Lesson: always check.

3.7 Synthetic data (Part 5): what it is and why

Synthetic data = training examples written by another AI model instead of by humans. Our problem: MedQA gives only the correct letter, for example "Answer: D) Nitrofurantoin", with no reasoning. A model trained on letters learns to guess. So we ask a bigger, stronger model (the teacher, Qwen2.5-14B-Instruct) to explain WHY the given correct answer is right. This is called rationale generation: the teacher is told the answer, so it explains instead of guessing.

Before and after (one MedQA training target):

BEFORE:  Answer: D) Nitrofurantoin
AFTER:   Answer: D) Nitrofurantoin
         Explanation: Nitrofurantoin is a first-line choice for uncomplicated cystitis in pregnancy because ...

distilabel is the library that runs this as a pipeline: load rows -> send each to the teacher -> collect the replies -> save. A quality filter then throws away bad explanations (too short, too long, or not mentioning the correct option). Risk: the teacher can be wrong in subtle ways, so you always read a random sample yourself.

3.8 DPO (Part 6A): learning from "better vs worse"

DPO needs triples: a prompt, a chosen answer (better) and a rejected answer (worse). We create them from your own SFT model: it answers each prompt twice at high temperature (so the answers differ), the teacher answers once, the teacher rates all three (1-5), and for qa we also check whether the letter is correct. Best = chosen, worst = rejected.

DPO then raises the probability of chosen answers and lowers rejected ones, while a reference model (a frozen copy of your SFT adapter) keeps it from drifting too far. beta = 0.1 controls the strength of that leash. At step 0 the model equals the reference, so the DPO loss is exactly ln 2 = 0.693; it falls as the model learns the preferences.

def clean(text):
    """Collapse repeated spaces/newlines and strip the ends."""
    return re.sub(r"[ \t]+", " ", re.sub(r"\n{3,}", "\n\n", str(text or ""))).strip()


def key(text):
    """Normalised text used to find duplicates (lower-case, letters and digits only)."""
    return re.sub(r"[^a-z0-9]", "", text.lower())[:300]


def mcq_prompt(question, options):
    """Question + lettered options, the exact user message format for the qa adapter."""
    lines = [f"{letter}) {text}" for letter, text in options]
    return f"{clean(question)}\n\nOptions:\n" + "\n".join(lines)


def short(text, limit=900):
    """Cut long explanations at the last full stop before `limit` characters."""
    text = clean(text)
    if len(text) <= limit:
        return text
    cut = text[:limit].rsplit(".", 1)[0]
    return cut + "."

    answer = f"Answer: {letter}) {clean(row['answer'])}"   # no explanation in MedQA (Part 5 adds one)
    return {"task": "qa", "source": "medqa", "answer_letter": letter,
            "question_key": key(row["question"]),
            "messages": chat("qa", mcq_prompt(row["question"], opts), answer)}


def from_medmcqa(row):
    if row.get("choice_type") != "single" or row.get("cop") not in (0, 1, 2, 3):
        return None                                # skip multi-answer or broken rows
    opts = list(zip(LETTERS, [row["opa"], row["opb"], row["opc"], row["opd"]]))
    letter = LETTERS[row["cop"]]
    answer = f"Answer: {letter}) {clean(opts[row['cop']][1])}"
    if row.get("exp") and len(clean(row["exp"])) > 40:
        answer += f"\nExplanation: {short(row['exp'])}"
    return {"task": "qa", "source": "medmcqa", "answer_letter": letter,
            "question_key": key(row["question"]),
            "messages": chat("qa", mcq_prompt(row["question"], opts), answer)}


def from_pubmedqa(row):
    context = clean(" ".join(row["context"]["contexts"]))
    opts = [("A", "yes"), ("B", "no"), ("C", "maybe")]
    letter = {"yes": "A", "no": "B", "maybe": "C"}[row["final_decision"]]
    question = f"Context: {context}\n\nQuestion: {row['question']}"
    answer = f"Answer: {letter}) {row['final_decision']}\nExplanation: {short(row['long_answer'])}"
    return {"task": "qa", "source": "pubmedqa", "answer_letter": letter,
            "question_key": key(row["question"]),
            "messages": chat("qa", mcq_prompt(question, opts), answer)}

def compact(value):
    """Drop empty fields ("None", "", [], {}) so the target JSON is short and factual."""
    if isinstance(value, dict):
        out = {k: compact(v) for k, v in value.items()}
        return {k: v for k, v in out.items() if v not in (None, "", [], {})}
    if isinstance(value, list):
        out = [compact(v) for v in value]
        return [v for v in out if v not in (None, "", [], {})]
    if isinstance(value, str) and value.strip().lower() in ("none", "n/a", ""):
        return None
    return value


def from_clinical(row):
    """One raw row gives one 'notes' example and one 'summary' example (or None if broken)."""
    conversation, note = clean(row["conversation"]), clean(row["note"])
    try:
        summary = compact(json.loads(row["summary"]))   # ~25% of summaries are invalid JSON
    except (json.JSONDecodeError, TypeError):
        return None
    if not conversation or not note or not summary:
        return None
    summary_text = json.dumps(summary, ensure_ascii=False)
    notes_ex = {"task": "notes", "source": "clinical_notes", "id": row["idx"],
                "messages": chat("notes", conversation, note)}
    summary_ex = {"task": "summary", "source": "clinical_notes", "id": row["idx"],
                  "messages": chat("summary", note, summary_text)}
    return notes_ex, summary_ex


def fits(example):

    """Apply a converter, drop None/too-long rows."""
    out = [fn(r) for r in rows]
    return [x for x in out if x is not None]

    from transformers import AutoTokenizer

    print(f"(tokenizer not loaded, skipping token counts: {exc.__class__.__name__})")

    lengths = []
    for n, line in enumerate(path.open(encoding="utf-8"), start=1):
        try:
            row = json.loads(line)                  # 1) each line must be valid JSON
            roles = [m["role"] for m in row["messages"]]
            assert roles == ROLES, f"roles {roles}"  # 2) exactly system -> user -> assistant
            assert all(m["content"].strip() for m in row["messages"]), "empty message"
            if row["task"] == "summary":            # 3) summary targets must be valid JSON

                lengths.append(len(ids))
        except Exception as exc:
            errors += 1
            print(f"ERROR {path.name}:{n}: {exc}")
    stats = f" tokens median={statistics.median(lengths):.0f} max={max(lengths)}" if lengths else ""
    print(f"{path.name:22} rows={n:>6}{stats}")

sys.exit(1 if errors else 0)

"""Step 4: QLoRA supervised fine-tuning (SFT) of Llama-3.1-8B-Instruct with Unsloth + TRL + PEFT.

One run = one task = one LoRA adapter, e.g.  python scripts/10_train_sft.py --task qa
"""
from unsloth import FastLanguageModel                    # import Unsloth FIRST so it can patch TRL/transformers
from unsloth.chat_templates import train_on_responses_only

import argparse                                          # command-line options
import json                                              # save the training log
from datasets import load_dataset                        # read our .jsonl files
from trl import SFTConfig, SFTTrainer                    # Hugging Face TRL trainer
from common import SFT, OUT, BASE_MODEL_4BIT

p = argparse.ArgumentParser()
p.add_argument("--task", required=True, choices=["qa", "notes", "summary"])
p.add_argument("--max-train", type=int, default=None, help="use only the first N training rows")
p.add_argument("--epochs", type=float, default=1.0)
p.add_argument("--max-steps", type=int, default=-1, help="stop after N steps (-1 = use epochs)")
p.add_argument("--lr", type=float, default=2e-4)        # LoRA learns fast; 2e-4 is the usual QLoRA rate
p.add_argument("--rank", type=int, default=16)          # LoRA rank r: size of the adapter matrices
p.add_argument("--batch", type=int, default=8)          # examples per GPU step
p.add_argument("--grad-accum", type=int, default=2)     # effective batch = batch x grad-accum = 16
p.add_argument("--train-file", default=None, help="override the training .jsonl (Part 5 uses this)")
p.add_argument("--run-name", default=None)
a = p.parse_args()
run = a.run_name or f"sft-{a.task}"
out_dir = OUT / "adapters" / run

# 1) Load the base model already quantised to 4-bit (this is the "Q" in QLoRA).
model, tokenizer = FastLanguageModel.from_pretrained(
    model_name=BASE_MODEL_4BIT,     # 4-bit NF4 weights: ~5.7 GB on disk instead of ~16 GB
    max_seq_length=2048,            # longest example we keep is ~1,600 tokens
    load_in_4bit=True,
    dtype=None,                     # None = auto: bfloat16 on A100/L40/H100
)

# 2) Attach small trainable LoRA matrices to every attention and MLP projection.
model = FastLanguageModel.get_peft_model(
    model,
    r=a.rank,
    lora_alpha=a.rank,              # scaling = alpha / r = 1.0
    lora_dropout=0.0,               # 0 is fastest in Unsloth and works well
    target_modules=["q_proj", "k_proj", "v_proj", "o_proj", "gate_proj", "up_proj", "down_proj"],
    use_gradient_checkpointing="unsloth",   # recompute activations to save VRAM
    random_state=3407,
)
model.print_trainable_parameters()  # expect ~42M trainable of ~8B (about 0.5%)


# 3) Turn each {"messages": [...]} row into one string using Llama-3.1's own chat template.
#    The template starts with <|begin_of_text|>; the trainer adds it again when tokenising,
#    so we remove it here to end up with exactly ONE begin token (double BOS hurts quality).
def to_text(batch):
    texts = [tokenizer.apply_chat_template(m, tokenize=False).removeprefix(tokenizer.bos_token)
             for m in batch["messages"]]
    return {"text": texts}


train_file = a.train_file or str(SFT / f"{a.task}_train.jsonl")

    output_dir=str(OUT / "checkpoints" / run),
    dataset_text_field="text",
    max_length=2048,
    per_device_train_batch_size=a.batch,
    gradient_accumulation_steps=a.grad_accum,
    num_train_epochs=a.epochs,
    max_steps=a.max_steps,
    learning_rate=a.lr,
    lr_scheduler_type="cosine",     # smooth decay to ~0 by the end
    warmup_steps=10,                # ramp the LR up for the first 10 steps
    optim="adamw_8bit",             # 8-bit optimiser states: big VRAM saving
    weight_decay=0.01,
    bf16=True,
    logging_steps=10,
    eval_strategy="steps",
    eval_steps=100,
    save_steps=200,
    save_total_limit=2,             # keep only the 2 newest checkpoints on disk
    report_to="none",
    seed=3407,
)
trainer = SFTTrainer(model=model, processing_class=tokenizer, train_dataset=train,
                     eval_dataset=val, args=cfg)

# 5) Only learn from the assistant's answer, not from the system/user text.
trainer = train_on_responses_only(
    trainer,
    instruction_part="<|start_header_id|>user<|end_header_id|>\n\n",

tokenizer.save_pretrained(str(out_dir))
(out_dir / "train_log.json").write_text(json.dumps(trainer.state.log_history, indent=1))
print(f"DONE adapter={out_dir} train_loss={stats.training_loss:.4f}")

"""Part 5: use distilabel + a teacher LLM to write explanations for MedQA answers (synthetic SFT data).

MedQA only gives the correct letter. A model trained on letters alone learns to guess, not to reason.
The teacher (Qwen2.5-14B-Instruct served by vLLM as "teacher") explains WHY the gold answer is right.

import os
import re
from distilabel.models import OpenAILLM                  # talks to any OpenAI-compatible server (vLLM)
from distilabel.pipeline import Pipeline
from distilabel.steps import LoadDataFromDicts
from distilabel.steps.tasks import TextGeneration
from common import DATA, SFT, read_jsonl, write_jsonl

p.add_argument("--limit", type=int, default=None, help="only explain the first N MedQA rows (test run)")

"""Evaluation step B: automatic metrics for every saved prediction file.

qa      -> accuracy (letter match), ROUGE-L, BERTScore
notes   -> ROUGE-L, BERTScore
summary -> JSON-valid rate, ROUGE-L, BERTScore
"""
import argparse
import json
import os
from pathlib import Path
from rouge_score import rouge_scorer                 # Google's reference ROUGE implementation
from bert_score import score as bert_score           # BERTScore (Zhang et al., 2020)
from common import OUT, read_jsonl

p = argparse.ArgumentParser()
p.add_argument("--tasks", nargs="+", default=["qa", "notes", "summary"])
p.add_argument("--bert-model", default=os.getenv("BERTSCORE_MODEL", "roberta-large"))
a = p.parse_args()

rouge = rouge_scorer.RougeScorer(["rougeL"], use_stemmer=True)   # stemmer: "infections" ~ "infection"


def letter(text):
    """'Answer: C) ...' -> 'C' (None if the model did not follow the format)."""
    if text and "Answer:" in text:
        tail = text.split("Answer:", 1)[1].strip()
        return tail[:1].upper() or None
    return None


def is_json(text):
    try:
        json.loads(text.strip().removeprefix("```json").removesuffix("```").strip())
        return True
    except (json.JSONDecodeError, AttributeError):
        return False


results = {}
for task in a.tasks:
    for path in sorted(Path(OUT / "preds" / task).glob("*.jsonl")):
        rows = read_jsonl(path)
        preds = [r["prediction"] or "" for r in rows]
        refs = [r["reference"] for r in rows]
        m = {"n": len(rows)}
        m["rougeL"] = sum(rouge.score(ref, pred)["rougeL"].fmeasure for ref, pred in zip(refs, preds)) / len(rows)
        _, _, f1 = bert_score(preds, refs, model_type=a.bert_model, lang="en", verbose=False)
        m["bertscore_f1"] = f1.mean().item()
        if task == "qa":
            m["accuracy"] = sum(letter(p_) == r["answer_letter"] for p_, r in zip(preds, rows)) / len(rows)
            m["format_ok"] = sum(letter(p_) is not None for p_ in preds) / len(rows)
        if task == "summary":
            m["json_valid"] = sum(is_json(p_) for p_ in preds) / len(rows)
        results[f"{task}/{path.stem}"] = {k: round(v, 4) if isinstance(v, float) else v for k, v in m.items()}
        print(f"{task:8} {path.stem:12} {results[f'{task}/{path.stem}']}")

"""Evaluation step C: LLM-as-a-judge.

--mode score     one answer at a time, 1-5 rubric score            (Part 5)
--mode pairwise  model A vs model B, run twice with order swapped    (Part 6)
                 -> removes position bias: a "win" must win in BOTH orders
"""
import argparse
import json
import os
import re
from concurrent.futures import ThreadPoolExecutor
from openai import OpenAI
from common import OUT, read_jsonl

p = argparse.ArgumentParser()
p.add_argument("--task", required=True, choices=["qa", "notes", "summary"])
p.add_argument("--mode", default="score", choices=["score", "pairwise"])
p.add_argument("--models", nargs="+", required=True, help="score: any number; pairwise: exactly two (A B)")
p.add_argument("--n", type=int, default=100)
a = p.parse_args()

judge = OpenAI(base_url=os.getenv("JUDGE_URL", "http://localhost:8001/v1"), api_key="EMPTY")
JUDGE_MODEL = os.getenv("JUDGE_MODEL", "teacher")
RUBRIC = {
    "qa": "correct final answer (vs the reference), sound medical reasoning, no unsafe advice",
    "notes": "faithful to the conversation (no invented facts), complete key findings, clear clinical style",
    "summary": "valid JSON, every value supported by the note, no important fact missing",
}


def ask_json(prompt):
    """Call the judge at temperature 0 and pull the first {...} object out of the reply."""
    text = judge.chat.completions.create(
        model=JUDGE_MODEL, temperature=0.0, max_tokens=300,
        messages=[{"role": "user", "content": prompt}]).choices[0].message.content
    match = re.search(r"\{.*\}", text, re.DOTALL)
    try:
        return json.loads(match.group(0)) if match else {}
    except json.JSONDecodeError:
        return {}


def score_prompt(row):
    return (f"You are a strict medical expert grader. Criteria: {RUBRIC[a.task]}.\n\n"
            f"TASK INPUT:\n{row['prompt'][:4000]}\n\nREFERENCE ANSWER:\n{row['reference'][:3000]}\n\n"
            f"MODEL ANSWER:\n{row['prediction'][:3000]}\n\n"
            'Return ONLY a JSON object: {"score": <1-5>, "reason": "<one sentence>"}')


def pair_prompt(row, first, second):
    return (f"You are a strict medical expert judge. Criteria: {RUBRIC[a.task]}.\n\n"
            f"TASK INPUT:\n{row['prompt'][:4000]}\n\nREFERENCE ANSWER:\n{row['reference'][:3000]}\n\n"
            f"ANSWER A:\n{first[:3000]}\n\nANSWER B:\n{second[:3000]}\n\n"
            'Which answer is better? Return ONLY a JSON object: {"winner": "A" or "B" or "tie", "reason": "..."}')


preds = {m: read_jsonl(OUT / "preds" / a.task / f"{m}.jsonl")[: a.n] for m in a.models}
report = {}
with ThreadPoolExecutor(max_workers=16) as pool:
    if a.mode == "score":
        for m, rows in preds.items():
            scores = [r.get("score") for r in pool.map(lambda row: ask_json(score_prompt(row)), rows)]
            valid = [s for s in scores if isinstance(s, (int, float))]
            report[m] = {"mean_score": round(sum(valid) / max(len(valid), 1), 3), "judged": len(valid)}
    else:
        ma, mb = a.models
        rows_a, rows_b = preds[ma], preds[mb]

        def duel(i):
            ab = ask_json(pair_prompt(rows_a[i], rows_a[i]["prediction"], rows_b[i]["prediction"]))
            ba = ask_json(pair_prompt(rows_a[i], rows_b[i]["prediction"], rows_a[i]["prediction"]))
            first, second = ab.get("winner"), ba.get("winner")
            if first == "A" and second == "B":
                return ma                                  # A won in both orders
            if first == "B" and second == "A":
                return mb
            return "tie"                                   # disagreement across orders = tie

        outcomes = list(pool.map(duel, range(min(len(rows_a), len(rows_b)))))
        n = len(outcomes)
        report = {f"{ma}_wins": round(outcomes.count(ma) / n, 3),
                  f"{mb}_wins": round(outcomes.count(mb) / n, 3),
                  "ties": round(outcomes.count("tie") / n, 3), "n": n,
                  "per_item": outcomes}                    # kept for judge-vs-human agreement (Part 7)

print(json.dumps({k: v for k, v in report.items() if k != "per_item"}, indent=1))
path = OUT / "reports" / f"judge_{a.task}_{a.mode}_{'_vs_'.join(a.models)}.json"
path.parent.mkdir(parents=True, exist_ok=True)
path.write_text(json.dumps(report, indent=1))

5.15 Common mistake at this level

The mistake: celebrating a metric that does not measure what you think: ROUGE-L rises because the model copies the reference style while facts get worse; accuracy rises because test questions leaked into training; the judge prefers the fine-tuned model because it writes like the judge.

How to spot it: read 10 random predictions next to their references; check format_ok before accuracy; keep the de-duplication (Section 4.4) and run the contamination check (Part 7); compare at least two independent metrics; run the significance test before claiming a win.

DPO in one paragraph (details in Part 3, section 3.8): SFT taught the model to imitate good answers. DPO teaches it to PREFER better answers over worse ones. You give it (prompt, chosen, rejected) triples; it increases the probability of the chosen answer and decreases the rejected one, while a frozen copy of the SFT model (the reference) stops it from drifting too far.

Where the pairs come from (real example shape from this pipeline):

prompt   : "Pediatric airway differs from adult - Options: A) Large tongue  B) Short epiglottis ..."
candidate 1 (your SFT model, temperature 0.9): "Answer: B) Short epiglottis ..."   -> wrong letter,  rating 2
candidate 2 (your SFT model, temperature 0.9): "Answer: A) Large tongue ..."       -> right letter,  rating 4
candidate 3 (teacher)                         : "Answer: A) Large tongue ..."       -> right letter,  rating 5
chosen   = candidate 3 (score 10 + 5 = 15)     rejected = candidate 1 (score 0 + 2 = 2)

Score = 10 points if the letter is correct + the judge's 1-5 rating. Ground truth always beats the judge.

"""Part 6: build DPO preference pairs (prompt, chosen, rejected) with distilabel.

For each held-out prompt we collect 3 candidate answers:
  2 samples from YOUR SFT adapter (served by vLLM under the adapter name, e.g. "qa")
  1 answer from the teacher model
The teacher then rates all 3 (UltraFeedback, 1-5). For qa we ALSO check the letter against the gold answer,
because a verifiable signal beats any judge. Best candidate = chosen, worst = rejected.
"""
import argparse
import os
from distilabel.models import OpenAILLM
from distilabel.pipeline import Pipeline
from distilabel.steps import GroupColumns, LoadDataFromDicts
from distilabel.steps.tasks import TextGeneration, UltraFeedback
from common import PREF, SYSTEM, read_jsonl, write_jsonl

p = argparse.ArgumentParser()
p.add_argument("--task", default="qa", choices=["qa", "notes", "summary"])
p.add_argument("--limit", type=int, default=1500)
a = p.parse_args()

STUDENT_URL = os.getenv("STUDENT_URL", "http://localhost:8000/v1")  # vLLM with your SFT adapters
TEACHER_URL = os.getenv("TEACHER_URL", "http://localhost:8001/v1")  # vLLM with the teacher
TEACHER = os.getenv("TEACHER_MODEL", "teacher")

rows = read_jsonl(PREF / f"{a.task}_dpo.jsonl")[: a.limit]
inputs = [{"instruction": r["messages"][1]["content"],                 # the user message
           "gold_letter": r.get("answer_letter")} for r in rows]       # None for notes/summary


def llm(model, url, temperature):
    return OpenAILLM(model=model, base_url=url, api_key="EMPTY",
                     generation_kwargs={"temperature": temperature, "max_new_tokens": 700})


with Pipeline(name=f"medscriptai-dpo-{a.task}") as pipeline:
    load = LoadDataFromDicts(data=inputs, batch_size=64)
    student_1 = TextGeneration(name="student_1", llm=llm(a.task, STUDENT_URL, 0.9),
                               system_prompt=SYSTEM[a.task], input_batch_size=32)
    student_2 = TextGeneration(name="student_2", llm=llm(a.task, STUDENT_URL, 0.9),
                               system_prompt=SYSTEM[a.task], input_batch_size=32)
    teacher = TextGeneration(name="teacher", llm=llm(TEACHER, TEACHER_URL, 0.3),
                             system_prompt=SYSTEM[a.task], input_batch_size=32)
    group = GroupColumns(columns=["generation", "model_name"],          # 3 single answers -> 1 list
                         output_columns=["generations", "generation_models"])
    rate = UltraFeedback(llm=llm(TEACHER, TEACHER_URL, 0.0), aspect="overall-rating", input_batch_size=16)
    load >> [student_1, student_2, teacher] >> group >> rate            # fan out, then join

data = pipeline.run(use_cache=False)["default"]["train"]


def letter_of(text):
    """Read the letter after 'Answer:' ('Answer: C) ...' -> 'C')."""
    if text and "Answer:" in text:
        tail = text.split("Answer:", 1)[1].strip()
        return tail[:1].upper() if tail else None
    return None


pairs = []
for row in data:
    scored = []
    for text, rating in zip(row["generations"], row["ratings"]):
        if not text or rating is None:
            continue
        correct = 1 if row["gold_letter"] and letter_of(text) == row["gold_letter"] else 0
        scored.append((correct * 10 + rating, text))    # correctness dominates, rating breaks ties
    if len(scored) < 2:
        continue
    scored.sort(key=lambda s: s[0])
    (low, rejected), (high, chosen) = scored[0], scored[-1]
    if high - low < 2:                                  # too similar = weak training signal, skip
        continue
    system = {"role": "system", "content": SYSTEM[a.task]}
    pairs.append({"prompt": [system, {"role": "user", "content": row["instruction"]}],
                  "chosen": [{"role": "assistant", "content": chosen}],
                  "rejected": [{"role": "assistant", "content": rejected}],
                  "score_chosen": high, "score_rejected": low})

write_jsonl(PREF / f"{a.task}_pairs.jsonl", pairs)
print(f"{len(pairs)} preference pairs from {len(inputs)} prompts")

"""Part 6: DPO preference alignment that continues from your SFT adapter.

python scripts/22_train_dpo.py --task qa     ->  outputs/adapters/dpo-qa
"""
from unsloth import FastLanguageModel, PatchDPOTrainer   # Unsloth first
PatchDPOTrainer()                                         # no-op in current Unsloth; kept for older versions

import argparse
import json
from datasets import load_dataset
from trl import DPOConfig, DPOTrainer
from common import PREF, OUT

p = argparse.ArgumentParser()
p.add_argument("--task", default="qa", choices=["qa", "notes", "summary"])
p.add_argument("--beta", type=float, default=0.1)       # how strongly to stay close to the SFT model
p.add_argument("--lr", type=float, default=5e-6)        # DPO needs a MUCH smaller LR than SFT
p.add_argument("--epochs", type=float, default=1.0)
a = p.parse_args()
sft_dir = OUT / "adapters" / f"sft-{a.task}"
out_dir = OUT / "adapters" / f"dpo-{a.task}"

# 1) Load base + your SFT adapter as TRAINABLE. DPO will keep improving these same LoRA weights.
model, tokenizer = FastLanguageModel.from_pretrained(str(sft_dir), max_seq_length=2048, load_in_4bit=True)
tokenizer.padding_side = "left"                           # TRL's DPO collator expects left padding

# 2) Preference data: {"prompt": [...], "chosen": [...], "rejected": [...]} (conversational format).
pairs = load_dataset("json", data_files=str(PREF / f"{a.task}_pairs.jsonl"), split="train")
pairs = pairs.select_columns(["prompt", "chosen", "rejected"])
split = pairs.train_test_split(test_size=0.05, seed=42)  # 5% held out to watch reward accuracy

cfg = DPOConfig(
    output_dir=str(OUT / "checkpoints" / f"dpo-{a.task}"),
    beta=a.beta,
    loss_type=["sigmoid"],                # the original DPO loss
    max_length=2048,                      # prompt + answer are truncated to this many tokens
    per_device_train_batch_size=2,        # each example = 2 sequences (chosen + rejected)
    gradient_accumulation_steps=8,        # effective batch 16 pairs
    num_train_epochs=a.epochs,
    learning_rate=a.lr,
    lr_scheduler_type="cosine",
    warmup_steps=10,
    optim="adamw_8bit",
    bf16=True,
    logging_steps=10,
    eval_strategy="steps",
    eval_steps=50,
    save_steps=200,
    save_total_limit=2,
    report_to="none",
    seed=3407,
)

# ref_model=None + a model that already has an adapter -> TRL copies it into a frozen "ref" adapter,
# so the reference policy is your SFT model (textbook DPO) without loading a second 8B model.
trainer = DPOTrainer(model=model, ref_model=None, args=cfg, processing_class=tokenizer,
                     train_dataset=split["train"], eval_dataset=split["test"])
print("adapters inside the model:", list(trainer.model.peft_config.keys()))   # expect ['default', 'ref']

trainer.train()
metrics = trainer.evaluate()
print({k: round(v, 4) for k, v in metrics.items() if "rewards" in k})   # accuracies should be > 0.5

# Save ONLY the trained adapter ("default"), not the frozen "ref" copy.
model.save_pretrained(str(out_dir), selected_adapters=["default"])
tokenizer.save_pretrained(str(out_dir))
(out_dir / "dpo_eval.json").write_text(json.dumps(metrics, indent=1))
print(f"DONE adapter={out_dir}")

import json
import os
import time
import uuid

from fastapi import FastAPI, Header, HTTPException
from langsmith import traceable                   # turns a function call into a LangSmith trace
from langsmith.wrappers import wrap_openai        # also traces every OpenAI-style call inside it
from openai import OpenAI
from pydantic import BaseModel, Field

from common import SYSTEM                         # SAME system prompts as training (no train/serve skew)

VLLM_URL = os.getenv("VLLM_URL", "http://localhost:8000/v1")
API_KEY = os.getenv("API_KEY", "")                # empty = no auth (local only); set it in production
TASK_TO_MODEL = {                                 # which adapter answers which task (change without code edits)
    "qa": os.getenv("MODEL_QA", "qa-dpo"),
    "notes": os.getenv("MODEL_NOTES", "notes"),
    "summary": os.getenv("MODEL_SUMMARY", "summary"),
}

llm = wrap_openai(OpenAI(base_url=VLLM_URL, api_key="EMPTY", timeout=120))
app = FastAPI(title="MedScriptAI", version="1.0.0")


class GenerateRequest(BaseModel):
    task: str = Field(pattern="^(qa|notes|summary)$", examples=["qa"])
    input: str = Field(min_length=1, max_length=20000)
    max_tokens: int = Field(default=700, ge=1, le=2000)
    temperature: float = Field(default=0.0, ge=0.0, le=1.5)


class GenerateResponse(BaseModel):
    request_id: str
    task: str
    model: str
    output: str
    parsed_json: dict | None = None               # filled for task="summary" when the output is valid JSON
    latency_ms: int
    disclaimer: str = "AI-generated. For education/documentation support only. Not medical advice."


@traceable(name="medscriptai.generate", run_type="chain")
def run_generation(task: str, text: str, max_tokens: int, temperature: float) -> dict:
    model = TASK_TO_MODEL[task]
    resp = llm.chat.completions.create(
        model=model,
        messages=[{"role": "system", "content": SYSTEM[task]}, {"role": "user", "content": text}],
        max_tokens=max_tokens,
        temperature=temperature,
    )
    return {"model": model, "output": resp.choices[0].message.content or ""}


@app.get("/health")
def health():
    """Liveness: the API process is up."""
    return {"status": "ok"}


@app.get("/ready")
def ready():
    """Readiness: vLLM answers and every adapter we route to is loaded."""
    try:
        served = {m.id for m in llm.models.list().data}
    except Exception as exc:
        raise HTTPException(503, f"vLLM not reachable: {exc.__class__.__name__}")
    missing = sorted(set(TASK_TO_MODEL.values()) - served)
    if missing:
        raise HTTPException(503, f"adapters not loaded in vLLM: {missing}")
    return {"status": "ready", "models": sorted(served)}


@app.post("/v1/generate", response_model=GenerateResponse)
def generate(req: GenerateRequest, x_api_key: str = Header(default="")):
    if API_KEY and x_api_key != API_KEY:
        raise HTTPException(401, "invalid or missing X-API-Key header")
    start = time.perf_counter()
    try:
        result = run_generation(req.task, req.input, req.max_tokens, req.temperature)
    except Exception as exc:
        raise HTTPException(502, f"model backend error: {exc.__class__.__name__}")
    parsed = None
    if req.task == "summary":
        try:
            parsed = json.loads(result["output"])
        except json.JSONDecodeError:
            parsed = None
    return GenerateResponse(request_id=str(uuid.uuid4()), task=req.task, model=result["model"],
                            output=result["output"], parsed_json=parsed,
                            latency_ms=int((time.perf_counter() - start) * 1000))

"""A fake OpenAI-compatible server (like vLLM) for testing pipelines and the API WITHOUT a GPU.

Run:  uvicorn tests.mock_openai:app --port 8000
It answers /v1/models and /v1/chat/completions with small, predictable replies.

import re
import time
from fastapi import FastAPI, Request

app = FastAPI()
MODELS = ["base", "qa", "notes", "summary", "qa-dpo", "notes-dpo", "teacher"]


def reply_for(model, text):
    """Pick a fake answer that has the same SHAPE as a real one."""
    n_texts = len(re.findall(r"<text \d+>", text))
    if n_texts:                                            # UltraFeedback judge request
        blocks = [f"#### Output for Text {i + 1}\nRating: {5 - i if i < 4 else 1}\nRationale: mock rationale."
                  for i in range(n_texts)]
        return "\n\n".join(blocks)
    if "The correct answer is:" in text:                   # teacher explanation request (Part 5)
        gold = text.split("The correct answer is:", 1)[1].splitlines()[0].strip()
        return (f"{gold} is correct because it best fits the key findings in the stem. "
                "The other options do not explain the presentation as well. (mock teacher)")
    if '"score": <1-5>' in text:                           # 32_judge.py --mode score
        return '{"score": 4, "reason": "mock grade"}'
    if '"winner"' in text:                                 # 32_judge.py --mode pairwise
        answer_a = text.split("ANSWER A:", 1)[1].split("ANSWER B:", 1)[0]
        return '{"winner": "%s", "reason": "mock"}' % ("A" if "dpo" in answer_a else "B")
    if "Return ONLY valid JSON" in text:                   # summary adapter
        return '{"visit motivation": "mock", "patient information": {"age": "40"}}'
    if "clinical case note" in text:                       # notes adapter
        return "A 40-year-old patient presented with mock symptoms."
    letter = "B" if model.startswith("qa") else "A"        # qa adapters / base / teacher
    return f"Answer: {letter}) mock option\nExplanation: mock explanation from {model}."


@app.get("/v1/models")

    return {"object": "list", "data": [{"id": m, "object": "model"} for m in MODELS]}


@app.get("/health")

@app.post("/v1/chat/completions")
async def chat(request: Request):
    body = await request.json()
    text = "\n".join(str(m.get("content", "")) for m in body.get("messages", []))
    content = reply_for(body.get("model", "base"), text)
    return {
        "id": "mock-1", "object": "chat.completion", "created": int(time.time()), "model": body.get("model"),

                     "message": {"role": "assistant", "content": content}}],
        "usage": {"prompt_tokens": len(text) // 4, "completion_tokens": len(content) // 4,
                  "total_tokens": (len(text) + len(content)) // 4},
    }

"""Elite check: is any TEST question a near-copy of a TRAINING question? (13-gram overlap, GPT-3 paper style)

Exact-match de-duplication (step 2) misses near-copies: the same question with one word changed.
Medical exams share stock phrases ("is brought to the emergency department because of a 2-day history of",
lab panels), so ONE shared 13-gram proves nothing. We flag a test question only when at least
50% of its 13-grams come from a SINGLE training question.
"""
import re
from collections import Counter, defaultdict
from common import SFT, read_jsonl

N = 13                       # n-gram length in words
THRESHOLD = 0.5              # share of the test question's n-grams found in one training question


def grams(text):
    text = text.split("\n\nOptions:")[0]                 # compare the question stem, not the option labels
    words = re.findall(r"[a-z0-9]+", text.lower())
    return {" ".join(words[i:i + N]) for i in range(len(words) - N + 1)}


for task in ["qa", "notes", "summary"]:
    index = defaultdict(set)                             # n-gram -> ids of training rows containing it
    path = SFT / f"{task}_train.jsonl"
    if path.exists():
        for row_id, row in enumerate(read_jsonl(path)):
            for g in grams(row["messages"][1]["content"]):
                index[g].add(row_id)
    test = read_jsonl(SFT / f"{task}_test.jsonl")
    flagged = []
    for row in test:
        test_grams = grams(row["messages"][1]["content"])
        per_train_row = Counter(i for g in test_grams for i in index.get(g, ()))
        best = per_train_row.most_common(1)[0][1] if per_train_row else 0
        if test_grams and best / len(test_grams) >= THRESHOLD:
            flagged.append(row["messages"][1]["content"][:110].replace("\n", " "))
    print(f"{task:8} test rows={len(test):4}  near-duplicates of training rows={len(flagged):3} "
          f"({len(flagged) / max(len(test), 1):.1%})")
    for text in flagged[:3]:
        print("   e.g.", text)

"""Elite check: is model B REALLY better than model A, or is it noise? Paired bootstrap on QA accuracy.

"""
import argparse
import random
from common import OUT, read_jsonl

p = argparse.ArgumentParser()
p.add_argument("--a", required=True)
p.add_argument("--b", required=True)
p.add_argument("--rounds", type=int, default=10000)
args = p.parse_args()


def correct(row):
    pred = row["prediction"] or ""
    letter = pred.split("Answer:", 1)[1].strip()[:1].upper() if "Answer:" in pred else None
    return int(letter == row["answer_letter"])


a = [correct(r) for r in read_jsonl(OUT / "preds" / "qa" / f"{args.a}.jsonl")]
b = [correct(r) for r in read_jsonl(OUT / "preds" / "qa" / f"{args.b}.jsonl")]

diffs = []
rng = random.Random(0)
for _ in range(args.rounds):
    idx = [rng.randrange(n) for _ in range(n)]          # resample the SAME questions for both models
    diffs.append(sum(b[i] - a[i] for i in idx) / n)
diffs.sort()
low, high = diffs[int(0.025 * args.rounds)], diffs[int(0.975 * args.rounds)]
observed = (sum(b[:n]) - sum(a[:n])) / n

def paths(value, prefix=""):
    """{"a": {"b": 1}, "c": [{"d": 2}]} -> {"a.b", "c.d"} (list items are merged)."""
    out = set()
    if isinstance(value, dict):
        for k, v in value.items():
            out |= paths(v, f"{prefix}{k.lower().strip()}.")
    elif isinstance(value, list):
        for v in value:
            out |= paths(v, prefix)
    elif value not in (None, "", "None"):
        out.add(prefix.rstrip("."))
    return out


def load(text):
    try:
        return json.loads((text or "").strip().removeprefix("```json").removesuffix("```").strip())
    except json.JSONDecodeError:
        return None


for model in a.models:
    rows = read_jsonl(OUT / "preds" / "summary" / f"{model}.jsonl")
    tp = fp = fn = invalid = 0
    for r in rows:
        ref, pred = paths(load(r["reference"]) or {}), load(r["prediction"])
        if pred is None:
            invalid += 1
            fn += len(ref)                     # an unreadable answer misses every criterion
            continue
        got = paths(pred)
        tp += len(ref & got)
        fp += len(got - ref)
        fn += len(ref - got)
    precision = tp / max(tp + fp, 1)
    recall = tp / max(tp + fn, 1)
    f1 = 2 * precision * recall / max(precision + recall, 1e-9)
    print(f"{model:10} field precision={precision:.3f} recall={recall:.3f} F1={f1:.3f} invalid_json={invalid}/{len(rows)}")

7.8 What elite teams would try next

  • RL with verifiable rewards (GRPO). For multiple-choice QA the reward is checkable (correct letter = 1). TRL's GRPOTrainer and Unsloth support it (verify current docs).
  • Other preference losses. DPO vs SimPO (TRL loss_type="sigmoid_norm"), IPO, KTO, ORPO on the same pairs, each with a significance test.
  • Iterative on-policy DPO. Regenerate pairs with the DPO model and train a second round; stop when the win rate stops moving.
  • Serving efficiency. FP8 or AWQ base model, prefix caching for the shared system prompt, speculative decoding; measure tokens per second and cost per 1,000 requests.
  • Safety evaluation. A red-team set (self-harm, dosing, emergencies) with expected refusals or escalation; track refusal rate next to helpfulness.
  • Privacy and regulation. Real notes contain patient data: de-identify, keep traces private, and know that software making clinical decisions is regulated (for example FDA "software as a medical device").

7.10 Common mistake at this level

The mistake: elite-looking analyses that are not tied to a decision: a kappa nobody reads, a CI computed on a different test set than the headline number, a leakage check run after the results are published.

How to spot it: write the question first ("is DPO better than SFT on QA accuracy?"), then the analysis, then the decision ("ship qa-dpo" or "keep qa").

ANSWER KEY

1. The trainer adds <|begin_of_text|> again, so every example starts with two BOS tokens. Training still runs, but the model learns from a sequence it never sees at inference (vLLM sends one BOS), which can hurt quality. The CPU smoke test caught exactly this.

2. 7,040 / (8 x 2) = 440 optimizer steps.

3. The default --max-loras is 1, so only one adapter can be active in a GPU batch; requests for the other two adapters wait for the next batches. Latency rises even though the GPU has capacity. With --max-loras 4 all three run in the same batch.

4. About 0.693 (= ln 2). At step 0 the policy equals the reference (the frozen "ref" copy of the SFT adapter), so both log-ratios are 0, the margin is 0 and -log(sigmoid(0)) = ln 2.

5. aws --endpoint-url http://localhost:4566 ecr describe-images --repository-name medscriptai-api (or set AWS_ENDPOINT_URL and drop the flag).

6. GPU billing stops, the root disk is kept, but /ephemeral is wiped, so the cache is lost (it re-downloads automatically). After Restore: run mkdir -p /ephemeral/hf-cache, update the IP if it changed, and restart FakeCloud.

7. Only that the observed difference is +1.6 points and NOT statistically significant: the interval contains 0. Do not claim an improvement; collect more test data or a bigger effect.

8. With swapping, A-then-B gives "A" (model 1) and B-then-A gives "A" (model 2), so the orders disagree and every item becomes a tie. The win rates are 0/0 and ties 100%: a clear signal of a broken or position-biased judge.

9. Set MODEL_QA=qa in deploy/.env and run docker compose --env-file .env up -d api in the deploy folder (only the API container restarts).

10. Least privilege: if the machine is compromised, the attacker can only read MedScriptAI's own image, bucket and secrets, not every image, bucket and secret in the account. "Resource": "*" is kept only for ecr:GetAuthorizationToken (it has no resource) and logs.
